# Xarajat to'sig'i (70%) + "To'lanmagan" — UI bo'laklari (HTML + CSS)

> **Bu fayl — dizayn spetsifikatsiyasi.** Birorta `.html` faylga TEGILMAGAN.
> Coder shu yerdagi bloklarni ko'chiradi va JS/SQL mantiqni yozadi.
>
> **Yangi prefikslar:** `.tos-*` (to'siq / balans paneli / blok xabari) · `.tlm-*` ("To'lanmagan" status).
> Mavjud klasslardan birortasi ham **qayta ta'riflanmaydi**. Mavjud klass faqat
> **yangi klass bilan birga** (kvalifikatsiya qilingan holda) ishlatiladi:
> `.jtbl tr.tlm-on td:first-child`, `.trow.tlm-on .tic`, `.jcard.tlm-on`, `.today.tos`.
> Ya'ni `.tlm-on` / `.tos` qo'yilmagan joyda hech narsa o'zgarmaydi.
>
> **Tokenlar:** faqat loyihada MAVJUD qiymatlar. Yangi rang o'ylab topilmagan —
> `--red`, `--red-soft`, `--surface`, `--surface-2`, `--line`, `--ink`, `--muted`, `--primary`.
> Ikkita yordamchi token qo'shiladi (§2.0), ularning qiymatlari **bayt-ma-bayt ko'chirilgan**:
> `--tlm-ink`/`--tlm-line` ← `hodim-dev.html` dagi `--red-ink`/`--red-line`,
> `--tos-warn`/`--tos-warn-soft` ← `jurnal-dev.html` dagi `--amber`/`--amber-soft`.
> Sabab: `hodim-dev.html` da `--amber` yo'q, `jurnal/provodka/professional/kassa` da `--red-ink` yo'q —
> bitta umumiy CSS blok bo'lishi uchun ikkalasi ham o'z nomi bilan e'lon qilinadi.
>
> **Spacing** — 4/8 shkalasi, **raw px** bilan (12px = `var(--s3)`, 16px = `var(--s4)`).
> Sabab: `--s*` faqat `hodim-dev.html` da bor; raw px 5 faylda ham **aynan bir xil** blok berish imkonini beradi.

## 1. 🔴 UCH XIL QIZIL — ma'no jadvali (chalkashmasin)

Sahifada qizil uch xil narsani anglatadi. Ular **shakli bilan** ajraladi, rangi bilan emas —
ya'ni rangni ko'rmaydigan foydalanuvchi ham farqlaydi.

| Ma'no | Vizual shakl | Klass | Qayerda | Ohang |
|-------|--------------|-------|---------|-------|
| **O'chirilgan yozuv** | `opacity:.65` + **usti chizilgan** (`line-through`) matn + 🗑 izoh qatori | mavjud `.jr.del` / `.jcard.del` / `.jdel-note` | jurnal | "yo'q qilingan" — **so'ngan** |
| **To'lanmagan (ochiq)** | **rozetka**: och qizil fon + qizil ramka + **to'ldirilgan qizil nuqta** + summa. Qator **bo'yalmaydi**, faqat chap chetida 3px qizil chiziq | **`.tlm`** + `.tlm-on` (qatorda) | jurnal, hodim ro'yxati, hodim paneli | "kutilmoqda" — **e'tibor** |
| **To'lanmagan edi (yopilgan)** | matnsiz **7px qizil nuqta** (`opacity:.55`) + tooltip | **`.tlm-was`** | jurnal, hodim ro'yxati | "tarix" — **deyarli sezilmas** |
| **Blok (to'siq)** | to'liq kenglikdagi **panel**: och qizil fon + chapda 3px qizil chiziq + ikonka + sarlavha + mini progress | **`.tos-blok`** | provodka, professional, banner | "harakat to'silgan" — **yo'l ko'rsatadi** |

Farqlash qoidalari:
- **To'ldirilgan (solid) qizil** butun tizimda faqat **ikki joyda**: `.tlm` rozetkasidagi nuqta va
  progress `.tos-fill` (blok holatida). Boshqa hamma joyda qizil — **och fon + to'q matn**.
- **`line-through` faqat o'chirilgan yozuvda.** `.tlm` hech qachon matnni chizmaydi.
- O'chirilgan yozuvda `.tlm` **umuman chizilmaydi** (coder: `if(e.is_deleted) → badge yo'q`).
  Agar baribir kelib qolsa, CSS uni susaytiradi (§3.2).
- **Sariq** (`--tos-warn`) — faqat "yaqin qoldi" (65–70%). Xato emas, ogohlantirish.
- **Yashil** (`--primary`) — "ochiq". Muvaffaqiyat rangi ham brend yashil (boshqa yashil yo'q).

### 4.5 Matn qoidalari (`#tosState` / `#tosNote`)

`x` = yozilgan xarajat, `k` = jami olingan pul, `pct = round(x/k*100)`, `yet = ceil(0.7*k − x)`.

| Holat | Klass (`#tosSect`) | Chip (`#tosState`) | Ikonka | `#tosNote` |
|-------|--------------------|--------------------|--------|------------|
| `k = 0` (hali pul olinmagan) | `s-ochiq` | `Kirim ochiq` | `unlock` | `Hali pul olinmagan.` (progress 0%, `#tosPct` = `—`) |
| `pct < 65` | `s-blok` | `Kirim yopiq` | `lock` | `Yana <b>{yet}</b> so'm xarajat yozsangiz kirim ochiladi.` |
| `65 ≤ pct < 70` | `s-yaqin` | `Oz qoldi` | `lock` | `Oz qoldi — yana <b>{yet}</b> so'm yozilsa kirim ochiladi.` |
| `pct ≥ 70` | `s-ochiq` | `Kirim ochiq` | `unlock` | `Kirim ochiq — olingan pulning <b>{pct}%</b> i yozilgan.` |
| `pct > 100` | `s-ochiq` | `Kirim ochiq` | `unlock` | `Kirim ochiq.` (bar 100% da to'xtaydi, `#tosPct` haqiqiy foizni ko'rsatadi) |

- `#tosFrac` = `{x} / {k} so'm` (masalan `700 000 / 1 000 000 so'm`).
- `#tosPct` = `52%` (yoki `—`).
- `#tosFill` kengligi: `Math.min(100, pct)+'%'`; `pct>0 && pct<2` bo'lsa `2%` (bir chiziq ko'rinsin).
- `#tosTrack` `aria-valuenow` = `Math.min(100,pct)`.
- To'lanmagan bo'lsa `#tosBal` dan `one` klassi olinadi (ikki ustun bo'ladi).
