## 1. A — Davr paneli (`.dav-*`)

### 1.1 Qaror
- Panel `.filters` kartasining eng tepasida, **manfiy margin bilan karta chetigacha yoyilgan**
  `--surface-2` tasmasi — qolgan filtrlardan vizual ajralib turadi (Aros uslubi), lekin yangi
  karta/soya qo'shilmaydi (ekran shovqinlanmaydi).
- Kalendar **sukut bo'yicha yashirin**; "Boshqa…" chipi uni ochadi (`.dav.cal-on`).
  Sabab: 90% holatda tayyor davr yetarli; ochiq kalendar mobil'da 2 qator joy yeydi.
  Ochilganda chiplar qatorining OSTIDA to'liq kenglikda chiqadi — 320px ekranda ham sig'adi.
- Tanlangan davr matni (`#davTxt`) **har doim** ko'rinadi: `Bugun · 24 avgust 2026`,
  `Bu oy · 1–24 avgust`, `1 iyul – 24 avgust 2026`.
- Mobil (`≤640px`): davr matni chiplardan **yuqoriga** chiqadi (`order:-1`), chiplar qatori
  gorizontal scroll bo'ladi (scrollbar ko'rinmaydi), balandligi 44px (touch).

### 1.3 JS uchun kontrakt
| Nom | Turi | Vazifa |
|-----|------|--------|
| `#davPanel` | div | `classList.toggle('cal-on')` — kalendarni ochadi/yopadi |
| `#davChips` | div | delegatsiya: `e.target.closest('.dav-chip')` → `btn.dataset.p` |
| `[data-p]` | `bugun` \| `hafta` \| `oy` \| `otgan` \| `custom` | 🔴 birinchi 4 tasi **mavjud `setRange(k)` kalitlari bilan aynan bir xil** |
| `.dav-chip.on` | klass | faol chip (bir vaqtda bitta). 🔴 **Default = `bugun`** — `boot()`/`init()` da `setRange('bugun')` chaqirilsin |

| `#davTxt` | span | matn: `formatDavr(from,to)` natijasi (§1.4) |

### 1.4 `#davTxt` matn qoidasi (o'zbekcha, lotin)
```
from === to                       → "24 avgust 2026"
bir oy ichida, from = oy boshi    → "1–24 avgust"
bir oy ichida                     → "5–24 avgust 2026"
turli oy/yil                      → "1 iyul – 24 avgust 2026"
```
Chip nomi oldiga qo'shiladi, `·` bilan: `Bugun · 24 avgust 2026`.
Oylar: `yanvar, fevral, mart, aprel, may, iyun, iyul, avgust, sentyabr, oktyabr, noyabr, dekabr`.

## 2. B — Dashboard (`.dash-*`)

### 2.1 Qaror
- Butun blok **bitta karta emas**: xulosa kartalari (4 ta kichik karta) + ikkita panel
  (breakdown ro'yxati · diagramma). Shu tufayli mobil'da tabiiy ravishda qatorlanadi.
- **Yig'iladigan**: `.dash.off` → `.dash-body{display:none}`, sarlavha chevroni −90° buriladi.
  Holat `localStorage['prov-jdash']` da saqlansin (`'off'` / `''`). 🔴 Mobil'da **sukut ochiq**
  qoldirilgan, chunki karta 4 ta va balandligi ~90px — jurnal pastga uzoq ketmaydi.
- **Legend alohida chizilmaydi** — breakdown ro'yxatining o'zi legend (rangli nuqta + nom + summa + %).
- Diagramma **inline SVG**, kutubxonasiz. `donut` ⇄ `bar` almashish tugmasi.
- Rang: `--dch-1..8` tsiklik (`i % 8`), 9-dan keyingilari "Boshqa" → `--dch-other` (neytral kulrang).
  Ro'yxat **kamayish tartibida** bo'lsin — eng katta ulush brend yashiliga tushadi.

## 3. C — Qidiruvli tanlagich (`.ssel-*`)

### 3.1 Qaror — 🔴 native `<select>` DOM da QOLADI
`.ssel` mavjud `<select>` ni **almashtirmaydi**, ustiga qo'yiladi:
`<select>` vizual yashiriladi (`.ssel-native`, screen-reader uchun ochiq emas —
`aria-hidden` + `tabindex="-1"`), `.ssel-btn` esa uning `value` ini ko'rsatadi.
Tanlanganda JS `sel.value = v; sel.dispatchEvent(new Event('change'))` qiladi.

**Nima uchun:** `#fil`/`#hodim`/`#acc` ni to'ldiruvchi va o'qiydigan mavjud kod
(`loadFilials`, `loadAccounts`, `applyFilters`, `exportExcel`) **umuman o'zgarmaydi** —
regression xavfi nolga tushadi. `.ssel` ro'yxatini shu `<select>` ning
`<optgroup>`/`<option>` laridan avtomatik qurish mumkin.

- Desktop: tugma ostida absolyut panel (`z-index:120` — mavjud `.modal`/`.mmodal` 200 dan past,
  `.chekov` 200, `.yimodal` 220, `.lmodal` 230 dan ham past → hech qanday modal bilan urishmaydi).
- Mobil (`≤899px`): pastdan chiquvchi **sheet** (`position:fixed`, `bottom:0`) + fon overlay
  (`#sselOv`, `z-index:118`). `bnav` (z 50) ostida qoladi — to'g'ri.
- Klaviatura: `↑ ↓` — `.ssel-opt.hl` siljiydi, `Enter` — tanlaydi, `Esc` — yopadi va
  fokusni `.ssel-btn` ga qaytaradi, `Home/End` — birinchi/oxirgi.

### 3.5 JS uchun kontrakt
| Nom | Vazifa |
|-----|--------|
| `.ssel[data-sel]` | qiymati = boshqariladigan native `<select>` ning **id** si (`fil`/`hodim`/`acc`/`xtur`) |
| `.ssel.open` | ochiq holat (CSS panelni ko'rsatadi, chevron 180° buriladi) |
| `.ssel-btn` | ochish/yopish; `aria-expanded` yangilanadi |
| `.ssel-val` | tanlangan matn; bo'sh qiymatda `.ph` klassi qo'shiladi (kulrang) |
| `.ssel-inp` | qidiruv; ochilganda `focus()` (🔴 mobil'da klaviatura ochilishi normal) |
| `.ssel-list` | ro'yxat; filtrlashda **butunlay qayta chiziladi** → keyin `icons()` |
| `.ssel-opt[data-v]` | `data-v` = `<option>.value` |
| `.ssel-opt.on` | tanlangan (`aria-selected="true"`) |
| `.ssel-opt.hl` | klaviatura kursori (`↑↓`), `scrollIntoView({block:'nearest'})` |
| `.ssel-none` | "Topilmadi" |
| `#sselOv` | `.on` klassi = ko'rinadi (faqat ≤899px da ta'sirli); bosilganda yopadi |
| `body.ssel-lock` | mobil sheet ochiq — sahifa scroll qotadi |
| tashqariga bosish | `document` da `pointerdown` → `!e.target.closest('.ssel')` bo'lsa hammasi yopiladi |
